Stays

Share across devices and security

Stays are encrypted with your passcode before they are stored, so nobody can read them without it. Without the step below they are saved on this device only.

Use the same data on every device

  1. In GitHub open Settings, Developer settings, Personal access tokens, Fine-grained tokens, then Generate new token.
  2. Under Repository access choose Only select repositories and pick sibsan-map. Under Repository permissions set Contents to Read and write.
  3. Paste the token here.

The token stays in this browser. Anyone with it can change the repository, so keep it to yourself. Devices without a token can still show the map colours after you unlock this page there; their changes stay on that device.
