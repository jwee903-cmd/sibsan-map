Connect the visit counter

The map needs somewhere to add up the visits. This uses a free Google Firebase database that stores only anonymous counts per day: no names, no phone numbers, no device information.

  1. Open console.firebase.google.com, sign in with Google and choose Create a project (name it sibsan-map-stats, switch Google Analytics off).
  2. In the left menu choose Build → Firestore Database → Create database. Pick the region asia-southeast1 (Singapore) and Start in production mode.
  3. Open the Rules tab, delete everything there, paste the rules below, then press Publish.
  4. Click the gear next to Project Overview → Project settings. Under Your apps press the </> (Web) button, give it any name, and press the copy icon on the code block shown (or copy just the apiKey). The Project ID is in the same code (projectId).
  5. Paste into the Web API key box below: pasting the whole code block fills in both boxes. Then press Connect.
